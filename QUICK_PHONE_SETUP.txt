  🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

  ❌ "Can't reach this page"
     → Check if both devices are on same WiFi
     → Run setup_phone_access.bat again
     → Try opening URL on computer first

  ❌ Page loads but looks broken
     → Clear phone browser cache
     → Refresh the page
     → Close and reopen browser

  ❌ Can't install as app
     → Use Chrome on Android or Safari on iPhone
     → Other browsers may not support installation
     → You can still bookmark and use as website
